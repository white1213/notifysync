# 常见问题排查

按症状找。所有问题先确认三台设备在**同一个 WiFi**（注意：有些路由器开了"AP 隔离/客户端隔离"，设备间互相看不见，需在路由器设置里关闭）。

## 1. "发现的新设备"里看不到对方

| 检查 | 说明 |
|---|---|
| 同一 WiFi？ | 手机没在走流量；电脑没插网线到另一个网段（WiFi 和有线是两个网络时不互通） |
| 两端都在运行？ | 电脑端托盘图标存在；手机端有"通知同步 · 运行中"常驻通知 |
| 路由器 AP 隔离 | 路由器管理页关闭"AP 隔离 / 客户端隔离 / 访客网络隔离" |
| 电脑防火墙 | 右键管理员运行 `windows/tools/allow-firewall.bat` |
| 等够 10 秒 | presence 广播周期 5 秒，加上拨号冷却，最长 ~15 秒出现 |

## 2. 配对时验证码不一致 / 配对失败

- 验证码不一致说明存在中间人或异常设备，**不要确认**，在两边都点拒绝/取消后重试
- "配对超时：对方长时间未确认" → 对方手机黑屏了，亮屏等弹窗
- "对方未开启配对或已拒绝" → 对方 60 秒没操作自动拒绝了，重来
- 卡死无法配对 → 两边都"解除配对"清理残留后重新配对（单侧残留会自动自愈，但手动清更快）

## 3. 同步经常断（核心痛点自查）

按顺序查手机端 **设置 → 保活自检**：

1. **通知使用权**变灰/未开启 → 系统更新或清理软件把它关了 → 重新开启；仍不行点"修复通知监听"
2. **电池白名单**未加 → 去设置
3. **厂商自启动**没开 → 这是国产 ROM 杀后台的主因，手机管家里允许自启动+后台
4. 常驻通知消失 = 服务被杀 → 打开 App 一次即恢复；频繁被杀就把 App 加入"最近任务锁定"（最近任务界面下拉锁定）
5. 电脑端：托盘图标在不在；设备离线会有 Windows 通知提醒——**有提醒是正常设计（状态可视化），提醒后几秒内会自动重连**

## 4. 电脑上收不到某台手机的通知

- 手机端"设备"页看该设备是否在线（绿点）
- 那个 App 的通知是否真的发了系统通知（手机下拉栏有吗）——有些 App 被系统限制了后台通知
- 常驻类通知（音乐/导航）默认不同步：设置 → 忽略常驻通知
- 微信"你收到一条消息"式通知：是微信自己的隐私设置（微信 → 我 → 设置 → 新消息通知 → 通知显示消息详情）

## 5. 验证码没被识别/复制

- 目前支持中英文常见验证码文案，数字 4-8 位，支持"730 122"空格分隔
- 不支持：3 位以下、9 位以上、字母混合（如 A3F2 取件码是有意不提取的）
- 电脑端"验证码自动复制"默认开启，可在设置关闭；关闭后仍可在历史列表点"复制"
- 手机端收到同步来的验证码通知，下拉通知栏点"复制验证码"按钮

## 6. 电脑端口被占用 / 启动报 EADDRINUSE

37312 端口被占：大概率是 NotifySync 已经在运行（托盘里找），或安全软件拦截。任务管理器结束旧进程再来；用 `netstat -ano | findstr 37312` 查占用。

## 7. 想彻底重置

- 电脑：托盘退出后删除 `%APPDATA%\notifysync-windows\`（配对、历史全部清空）
- 手机：设置 → 清空历史（历史）；系统设置 → 应用 → 清除数据（全部，含配对）

## 8. Android Studio 构建报错速查

| 报错关键词 | 处理 |
|---|---|
| `Could not resolve all files` / 下载卡住 | 网络/Mirror 问题：确认用工程自带镜像；File → Invalidate Caches / Restart |
| `SDK location not found` | 缺 `local.properties`：AS 通常自动生成；没有就新建一行 `sdk.dir=你的SDK路径` |
| `Unsupported class file major version` | Gradle JDK 不对：Settings → Build Tools → Gradle → 选 jbr-17 |
| `Compose Compiler` 版本报错 | 确认没改过 `app/build.gradle.kts` 里的 Kotlin/Compose 版本号（1.9.22 / 1.5.8 是配套的） |

## 9. 隐私说明

- 通知只在局域网内、配对设备间、端到端加密传输；没有任何服务器参与
- 电脑端历史保存在本机 `%APPDATA%\notifysync-windows\notifications.json`（明文，注意电脑本身的安全）；手机端在应用私有目录 SQLite
- 解除配对会同时删除双方配对记录；对方不再能连接你
